# 📋 Sistema de Gestão de Tarefas — Alexya Kids

Este repositório contém a aplicação web desenvolvida para a organização e acompanhamento das tarefas operacionais, rotinas e metas diárias da **Alexya Kids**.

---

## 🎯 Objetivo
Facilitar a gestão das atividades do negócio de moda infantil, permitindo o controle de pendências, prazos e rotinas da loja de forma simples e intuitiva.

---

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação de conteúdo)
* **CSS3** (Estilização e design responsivo)
* **JavaScript** (Lógica de interação e gerenciamento de tarefas)

---

## 🚀 Como Executar
1. Faça o download do arquivo `Tarefas do Negócio — Alexya Kids.html`.
2. Abra o arquivo diretamente em qualquer navegador (Google Chrome, Microsoft Edge, etc.).
